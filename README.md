# Android BDD Test Automation Framework

This repository contains a comprehensive Kotlin-based test automation framework for Android applications, utilizing BDD with Cucumber and Espresso.

## Structure
- Step Definitions: `src/main/kotlin/com/example/stepdefinitions/`
- Page Objects: `src/main/kotlin/com/example/pages/`
- Features: `src/test/resources/features/`

## Getting Started
1. Clone the repo
2. Run tests with Gradle

## Security
Credentials are handled securely via environment variables.
